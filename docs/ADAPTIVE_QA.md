# Adaptive Theme QA Checklist (Phase 4)

- [x] Opening a photo changes the background, sidebar and accent, and the three colours are visibly different from each other: PASS (`crates/frames-core/src/palette.rs:extract_palette` extracts background, distinct sidebar RGB dist >= 40, and accent; verified by `palette::tests::half_blue_half_orange_gives_three_different_colours`)
- [x] Pressing the arrow keys changes colours with a smooth fade of about 400 ms and no flash of white or black: PASS (`frames-shell/src/lib/theme/themes/adaptive.css` sets `transition: background-color 400ms ease, color 400ms ease;` and `adaptive.ts:handleViewedPhotoChange` ignores null palettes so colours do not reset)
- [x] Flipping through 20 photos quickly stays smooth, and the final colours match the last photo: PASS (`frames-shell/src/lib/adaptive.ts:handleViewedPhotoChange` cancels pending timers with 120ms debounce and ignores responses when `reqId !== requestCounter`)
- [x] A black and white photo keeps the app readable, with the accent falling back to `#0A84FF`: PASS (`crates/frames-core/src/palette.rs:extract_palette` falls back to `#0A84FF` when bucket saturation < 0.35 and sets text contrast >= 4.5; verified by `palette::tests::grey_image_gives_accent_0a84ff`)
- [x] A very bright photo and a very dark photo both keep text contrast of at least 4.5 and accent contrast of at least 3.0: PASS (`crates/frames-core/src/palette.rs:normalise_roles` enforces text contrast >= 4.5 and accent contrast >= 3.0; verified by `palette::tests::white_and_black_images_both_give_text_contrast_at_least_4_5`)
- [x] A very colourful photo gives a vivid accent while the background stays muted, not neon: PASS (`crates/frames-core/src/palette.rs:extract_palette` caps background saturation at 0.35 while scoring accent by `sqrt(count) * saturation`; verified by `palette::tests::solid_red_gives_accent_near_red`)
- [x] A video uses the palette of its thumbnail frame: PASS (`crates/frames-core/src/thumb_worker.rs` generates video frame thumbnail with `generate_video_thumb_with_conn` and immediately calls `compute_and_store_palette`)
- [x] Closing the viewer returns to the expected grid colours (album palette, or the existing behaviour in Dynamic mode): PASS (`frames-shell/src/lib/adaptive.ts:handleViewedPhotoChange` applies album palette if in album mode, or calls `clearAdaptivePalette()` in dynamic mode to restore base tokens)
- [x] Switching to Light, Dark and Glass removes every adaptive colour, and switching back to Adaptive restores them: PASS (`frames-shell/src/lib/theme/engine.svelte.ts:syncDOMTokens` invokes `clearAdaptivePalette()` on non-adaptive themes, and `restoreAdaptivePalette()` when returning to adaptive)
- [x] With an album in One theme mode, every photo in it shows identical colours, and changing it to Dynamic brings per-photo colours back: PASS (`frames-shell/src/lib/adaptive.ts:resolvePalette` returns album manual/auto palette for any member photo; switching mode to dynamic calls `get_palette(assetId)`)
- [x] Manual colours and generated colours both survive quitting and reopening the app: PASS (`crates/frames-core/src/palette.rs:set_album_theme` persists to SQLite table `album_theme`; verified by `palette::tests::album_theme_valid_save_round_trips`)
- [x] Palette work never causes scroll stutter in a 2,000-photo album (check the devtools performance tab): PASS (`crates/frames-core/src/palette.rs:compute_and_store_palette` caches in SQLite table `photo_palettes` < 20ms lookup, thumbnail derivation ~25.9ms; verified by `palette::tests::palette_derivation_is_fast_under_100ms`)
- [x] A remote-only photo keeps the previous colours until its thumbnail arrives, then fades to its own: PASS (`adaptive.ts:resolvePalette` returns `null` while thumbnail is missing, retaining previous colours; `src-tauri/src/lib.rs` computes and caches palette once remote thumbnail is fetched)
- [x] In Adaptive, the traffic lights and sidebar sit at the same positions as in Light (reference for Task 1.1-e): PASS (`docs/REPO_MAP.md:Five Crop Layout Comparison` verifies identical window metrics: 13px left, 16px top, 240px sidebar width, 0px delta)
