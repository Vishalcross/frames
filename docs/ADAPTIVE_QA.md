# Adaptive Theme QA Checklist (Phase 4)

This document records the verification of the Adaptive colour theming system against the 14 QA criteria.

| # | Check | Status | Evidence |
|---|---|---|---|
| 1 | **Palette extraction matches the 5-colour role specification** (`bg`, `sidebar`, `accent`, `on_bg`, `on_sidebar`) | **PASS** | `crates/frames-core/src/palette.rs:extract_palette` extracts background, sidebar (+0.04 L), chroma accent (>=30° hue diff), and WCAG AA text colours; verified by `palette::tests::half_blue_half_orange_gives_three_different_colours`. |
| 2 | **Contrast ratios for text meet WCAG AA (>= 4.5:1) in all generated palettes** | **PASS** | `crates/frames-core/src/palette.rs:normalise_roles` computes `contrast_ratio` against `#FFFFFF` and `#111111` guaranteeing >= 4.5:1; verified by `color::tests::contrast_ratio_black_and_white` and `palette::tests::solid_red_gives_accent_near_red`. |
| 3 | **Contrast ratio between accent and background is >= 3.0:1** | **PASS** | `crates/frames-core/src/palette.rs:normalise_roles` clamps accent lightness (0.45..=0.65) vs bg (0.10..=0.18) with a loop ensuring `contrast_ratio(acc_rgb, bg_rgb) >= 3.0`; verified by `palette::tests::half_blue_half_orange_gives_three_different_colours`. |
| 4 | **Monochromatic / grey images fall back to accent #0A84FF** | **PASS** | `crates/frames-core/src/palette.rs:extract_palette` sets `#0A84FF` fallback when chroma is below threshold; verified by `palette::tests::grey_image_gives_accent_0a84ff`. |
| 5 | **Palettes are cached in `photo_palettes` and not recomputed on every view** | **PASS** | `crates/frames-core/src/thumb_worker.rs:compute_and_store_palette` writes to SQLite table `photo_palettes` after 256px thumbnail creation; `adaptive_commands.rs:get_palette` checks cached table before computing. |
| 6 | **Rapid arrow-key flipping in the viewer does not thrash the UI** | **PASS** | `frames-shell/src/lib/adaptive.ts:handleViewedPhotoChange` enforces 120ms debounce and ignores responses from superseded `requestCounter` IDs. |
| 7 | **A photo with no cached palette keeps previous colours until the new one arrives** | **PASS** | `frames-shell/src/lib/adaptive.ts:resolvePalette` returns `null` for uncomputed photos; `handleViewedPhotoChange` only calls `applyPalette` when a non-null palette is resolved, avoiding flashes. |
| 8 | **Album themes: Dynamic mode follows the photo** | **PASS** | `frames-shell/src/lib/adaptive.ts:resolvePalette` queries `get_palette(assetId)` when `theme.mode === 'dynamic'`; verified by `test_adaptive_palette.ts` Case 1. |
| 9 | **Album themes: Album auto mode derives a palette from the album's photos** | **PASS** | `crates/frames-core/src/album_palette.rs:derive_album_palette` derives dominant hue and accent across up to 20 album thumbnails; verified by `album_palette::tests::ten_fake_palettes_dominated_by_blue_gives_blue_accent`. |
| 10 | **Album themes: Album manual mode lets the user set 3 colours** | **PASS** | `frames-shell/src/lib/components/collections/AlbumThemeSettings.svelte` inputs Background, Sidebar, Accent and calls `set_album_theme`; verified by `palette::tests::album_theme_valid_save_round_trips`. |
| 11 | **Album manual mode rejects invalid hex colours** | **PASS** | Frontend regex `^#[0-9A-Fa-f]{6}$` in `AlbumThemeSettings.svelte` and backend validation in `palette.rs:set_album_theme`; verified by `palette::tests::album_theme_manual_save_with_two_colours_is_rejected`. |
| 12 | **Album manual mode warns on low text contrast** | **PASS** | `AlbumThemeSettings.svelte` computes `hasLowContrast` and displays `⚠️ Low text contrast` badge when text contrast is under 4.5:1 without blocking saving. |
| 13 | **Switching between themes preserves and reapplies colours cleanly** | **PASS** | `frames-shell/src/lib/theme/engine.svelte.ts:syncDOMTokens` calls `clearAdaptivePalette()` when switching away, and `restoreAdaptivePalette()` when returning to Adaptive theme. |
| 14 | **Palette derivation is fast (< 100ms per 256px thumbnail)** | **PASS** | 256x256 thumbnail derivation benchmarked at ~26ms unoptimized; verified by `palette::tests::palette_derivation_is_fast_under_100ms`. |
